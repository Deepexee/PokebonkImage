# PokebonkImage

Discord Rich Presence pictures for the PokeBonk desktop toolkit:
the map ground + the partner Pokémon in the middle, 256×256.

- `<map>-<dex>.png` normal, `<map>-<dex>-s.png` shiny
- `index.json` lists every picture that exists

Made by `tools/make_rpc_images.py` from PokeBonk's public assets (pokebonk.com).
Pokémon sprites: PMD SpriteCollab (sprites.pmdcollab.org), CC BY-NC 4.0.
